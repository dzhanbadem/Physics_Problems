To find all possible equivalent resistances using exactly three $1\,\Omega$ resistors, we must look at every possible combination of series and parallel configurations.

### Possible Configurations

1. **All three in series:**
* $R_{\text{eq}} = 1\,\Omega + 1\,\Omega + 1\,\Omega = \mathbf{3\,\Omega}$


2. **All three in parallel:**
* $\frac{1}{R_{\text{eq}}} = \frac{1}{1\,\Omega} + \frac{1}{1\,\Omega} + \frac{1}{1\,\Omega} = 3$
* $R_{\text{eq}} = \mathbf{0.33\,\Omega}$ (or $1/3\,\Omega$)


3. **Two in series, one in parallel:**
* First, the series pair: $1\,\Omega + 1\,\Omega = 2\,\Omega$.
* Then, combine with the third resistor in parallel:
* $\frac{1}{R_{\text{eq}}} = \frac{1}{2\,\Omega} + \frac{1}{1\,\Omega} = 0.5 + 1 = 1.5$
* $R_{\text{eq}} = \frac{1}{1.5} = \mathbf{0.67\,\Omega}$ (or $2/3\,\Omega$)


4. **Two in parallel, one in series:**
* First, the parallel pair: $\frac{1}{R_p} = \frac{1}{1\,\Omega} + \frac{1}{1\,\Omega} = 2 \implies R_p = 0.5\,\Omega$.
* Then, add the third resistor in series:
* $R_{\text{eq}} = 0.5\,\Omega + 1\,\Omega = \mathbf{1.5\,\Omega}$ (or $3/2\,\Omega$)

By combining three $1\,\Omega$ resistors, you can create the following four unique equivalent resistances:

* **$0.33\,\Omega$** ($1/3\,\Omega$)
* **$0.67\,\Omega$** ($2/3\,\Omega$)
* **$1.5\,\Omega$** ($3/2\,\Omega$)
